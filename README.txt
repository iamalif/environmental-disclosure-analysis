# Project Execution Instructions

## Data Setup
Due to file sizes, the original dataset downloaded from OneDrive is not included in this submission. To run the script successfully, please follow these steps:

1. Locate the folder named `Files/txt_files` in the project directory.
2. Place all required `.txt` data files into that folder.
3. If you do not have the dataset, please contact us and we can provide the necessary text files upon request.

**Note:** The script is designed to read directly from the `Files/txt_files` directory. It will not run correctly if these files are missing.
